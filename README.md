# Contact Management System

A simple GUI-based Contact Management System developed using Python and Tkinter as part of my Software Development Internship Task.

# Features

- Add Contact
- Search Contact
- Delete Contact
- View Contacts
- Store Contacts using JSON File
- User-Friendly GUI Interface

# Technologies Used

- Python
- Tkinter
- JSON
- File Handling

# Project Files

- `contact_gui.py` → Main Python GUI application
- `contacts.json` → Stores contact data

# How to Run

1. Open the project folder in VS Code
2. Open terminal
3. Run the following command:

```bash
python contact_gui.py
